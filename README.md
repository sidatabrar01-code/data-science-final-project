# SpaceX Falcon 9 Landing Prediction

## Project Overview

This project predicts whether the first stage of a SpaceX Falcon 9 launch will successfully land.

The project uses machine learning classification techniques to analyze SpaceX launch data and predict landing outcomes.

## Models Used

- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree
- K-Nearest Neighbors (KNN)

## Techniques

- Data preprocessing
- Feature standardization
- Train-test split
- GridSearchCV
- Model evaluation
- Confusion matrix
- Accuracy comparison

## Dataset

The project uses the SpaceX dataset provided as part of the IBM Data Science Professional Certificate Applied Data Science Capstone.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Result

The trained classification models are evaluated using test-set accuracy and confusion matrices to compare their performance.
